## ProbablyTranslator v2.8.0 — теги статусов, анимации, новые скроллбары

- **Статусы строк — настоящие скруглённые тэги** (Новая / Изменена / Длинная / Готово / Пусто), типы CSV/DLL — тоже тэги. Статус в редакторе справа оформлен так же и плавно меняет цвет.
- Таблица переписана на виртуализированный canvas: открывается мгновенно даже на десятках тысяч строк, плавный скролл колесом, подсветка строки под курсором, плавное выделение, зелёная вспышка при сохранении, каскадное появление строк, перетаскиваемый разделитель «Оригинал | Перевод», навигация клавишами.
- **Тонкие скроллбары** без стрелок: ползунок утолщается и подсвечивается при наведении (таблица, библиотека, поля редактора).
- **Компактные уведомления** вместо большой плашки.
- **Крупнее текст нижней панели** (+2 пт), статус-бар выше.
- Новые эффекты: счётчик переведённых строк «набегает», пульсация рамки прогресса автоперевода, затухание текста при смене строки, вспышка карточки мода при клике, плавное появление названия мода.

Файл `ProbablyTranslator.exe` собирается автоматически GitHub Actions.
