## ProbablyTranslator v2.6.0 — новый визуальный стиль

Структура окна прежняя (библиотека · таблица · редактор), полностью обновлено оформление:
- Новая палитра «графит + индиго» с единой системой цветов (`Theme`), мягкие границы и более крупные скругления.
- Эмодзи убраны из кнопок, бейджей и подписей (на Windows они рисовались мелкими нечёткими значками): чистая типографика и простые символы ●, ○, ▲, ↑, ↻.
- Фильтры и категории — компактные «таблетки», иерархия кнопок: «Автоперевод» (основная), «В игру» (акцент), «Собрать» (вторичная).
- Карточки редактора с цветными маркерами заголовков, увеличенная высота строк таблицы, чище заголовки колонок.
- Всё из v2.5.0: быстрая загрузка, фоновые операции, автосохранение.

Файл `ProbablyTranslator.exe` собирается автоматически GitHub Actions.
